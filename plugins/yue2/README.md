# YuE2 楽曲生成と独立エディタ

Homeの音声グループには以下のアプリがあります。

- **楽曲生成（YuE2）**：スタイル・歌詞・ABCを文字列として入力し、楽曲を生成します。
- **楽曲編集**：ABCエディタと譜面エディタの組です（下記）。
- 独立したアイテムとして、**歌詞エディタ**（セクション名と歌詞をカードで編集し、追加・削除・並べ替え）、
  **ABCエディタ**（ABCを楽曲パート単位の文字列で編集し、全体の楽譜表示・旋律の試聴）、
  **譜面エディタ**（楽曲パートをピアノロールで編集）、**曲からABC**があります。

楽曲生成を開くと4窓のグループで起動します（左上 歌詞エディタ、左下 楽曲生成、右上 曲からABC、右下 AIプロンプト生成）。
生成側の歌詞は起動時に歌詞エディタへリンクされます。ABCは生成側が自分で持ち、ABCエディタの中身を使うときは
エディタのリスト全体のグリップから生成側のABCへ運びます（ABCエディタは楽曲編集アプリの側にあります）。

**楽曲編集**（アプリ）は左にABCエディタ、右に**譜面エディタ**を並べて開きます。譜面エディタは楽曲パートのリストを入力に
（起動時にエディタの`abc`の`sections`と**シェア**します。ロールでの編集がそのままエディタのパートに書かれます）、
ヘッダー（拍子・音符の基準長・調を知るためだけの、エディタの`header`からのリンク）を持ち、カードのカードバーの移動ボタンでどのパートを開くかを切り替えます。
ピアノロールは開いているパート1つ分です。方言の外のパートはロールで開けず、警告に理由が出ます（ABCエディタでテキストとして編集します）。
ABCエディタの一覧の各パートは文字列のみです。

譜面エディタは、アイテムの本体がロールのカード1枚です（セクションはありません）。カードの見出しの拡大ボタンを押すとカードの枠がなくなってウィンドウいっぱいに広がり、ウィンドウのタイトルバーの解除ボタンで戻ります（アイテムの本体がカード1枚のときコアが自動で付ける拡大。拡大中は見出しも消えます）。ロールは全部の音高の行を見せる高さで、窓が低いときは窓が縦にスクロールします。
カードのカードバーは積まれた段でできています。1段目は譜面全体の操作で、**レイヤ**（左。ポップアップのチェックリスト）、移動ボタンと再生（中央。ABCプレビューの再生ツールと同じ並び）、拡大率（右。コアの**パーセント**コントロール：ラベルはなく、数値が中央で「％」付き、左右に常時 −／＋。数値を押すと直接入力になり、％とボタンは消えます）です。
グリッドの選択はなく、音符を置く刻みは拡大率に付いてきます（拡大すれば細かく、縮めば粗く。譜面自身が乗っている刻みより粗くはなりません）。
中央は「最初から（先頭にいるときは前の楽曲パートへ）・前の小節へ・再生・次の小節へ・次の楽曲パートへ」で、アイコンは大きな移動が skip-backward／forward、小さな移動が skip-start／end です。
再生ボタンに今のパートが「▶ Intro（イントロ）(1/3)」のように入ります。再生は譜面の縦線（再生位置）から始まり、チェックを入れたレイヤ（Vocal・Ins・コード）を簡易音源で鳴らします（コードは根音から重ねた和音を、次のコードまで伸ばして鳴らします）。
レイヤのチェックは、そのまま譜面に表示するものでもあります（外したレイヤの音符・コードは描かれず、コードを外すとコード段も操作できません）。
新しい音符は、最後に選んだ音符の声部に入ります（両方の声部を出しているときは、入る声部でない方が薄く描かれます。もう一方に入れたいときは、そちらだけを出すか、音符を作ってからレイヤを変えます）。
縦線は、移動ボタン・音符やコードの選択・小節番号のクリックで動きます。
前後の小節・パートへ動くと、そこでいちばん最初にある音符（表示しているレイヤの中で、同時なら Vocal）が自動で選ばれます（音符がなければ選択は外れます）。選んでいる音符をもう一度クリックすると選択が外れます。
次の段は音符の操作で、選んでいる音符（コード）が**カード**になっています。カードは左に縦のヘッダ（ハンドル）があり、中身は中央ぞろえで、フォームと一番右の削除が入ります。前の音符へ／次の音符へ（同じ声部の前後、コードを選んでいるときはコード）のボタンはカードの外、左右です。
何も選んでいないときは、枠も削除ボタンもなく「音符未選択」のガイドだけです（前後の移動ボタンは残ります）。
カードの中身は値です：音符は `yue2.note`（レイヤ・音名・臨時記号・オクターブ・長さ）、コードは `yue2.chord`（根音・種類・ベース）というバリュー型で、フィールドごとにドロップダウンが並びます（コントロールは `yue2.notecard`、`note.js`）。ハンドルは今のところ、運ぶものを持ちません（押すとそう表示されます）。
フォームはコアの `fieldform` コントロールで、**レイヤ**のドロップダウン（音符の声部を変えます。コードのときは表示専用の「コード」。何も選んでいなければ表示専用の「音符未選択」だけ）に続けて、
音名・臨時記号・オクターブ・長さ（コードなら根音・種類・ベース）のドロップダウンが1つの枠に仕切りで並びます。ラベルは枠に出ず、ドロップダウンを開いた一覧の見出しに出ます。
ロールで開けないパートは、1段目の移動と再生だけが残り、理由が出ます。

**小節の選択**：小節は、見出しのクリック・小節移動ボタン・音符やコードの選択で選ばれ（縦線のある小節が選ばれた小節）、Escapeで外れます。
見出しは少し高く、左に**ハンドル**、小節番号は中央です。選んだ小節の見出しの右には、小節の**追加**と**削除**のアイコンボタンが出ます（音符やコードのある小節の削除は確認を挟みます）。
移動と追加には、シェルの**ガイド**（`mu-guides` / `mu-guide`、窓の配置と同じ見た目）を使います。ハンドルをつかむか追加ボタンを押すと、小節の前半・後半（←・→＝その小節の前・後ろ）がガイドとして出ます。
ハンドルは、ガイドの上へ動かして離すと、その位置へ小節を（中の音符とコードごと）移します。追加は、ガイドを押すとその位置に休符の小節を入れます（Escape・ほかの小節の選択で閉じます）。
小節をまたぐ音符は小節線で2つに切れます。小節がひとつもないときは、見出しの位置の追加ボタンで最初の小節を足します。

**曲からABC**（`yue2.transcribe`）：曲（音声）を入れて「ABCに変換」を押すと、ComfyUI 本体の
`SheetSage2AudioToABC`（モデルは `sheetsage2_bf16.safetensors`）が歌のメロディと楽器の旋律をABCに書き出します。
メロディのみ（カバー向け）／メロディとコードを選べ、結果は楽譜付きのカードで読んで聴けます（編集はしません）。
結果のグリップをABCエディタへ運ぶと、楽曲パートに分かれてピアノロールで編集できます（リンクにしないのは、
エディタで直した内容を上書きしないため）。楽曲生成グループの右列に並びます（曲からABC／AIプロンプト生成）。

エディタは生成アプリの子ではなく、それぞれ自分の文書を保持します。
エディタのリスト全体のグリップから生成側の歌詞・ABC入力へ貼り付けると文字列をコピーし、
リンクすると変更を追従させられます。生成側からエディタへの貼り付けも可能です。

ComfyUIにYuE2ノードと`models/checkpoints/yue2_3b_int8_convrot.safetensors`が必要です。
別名のチェックポイントはモデル一覧から選択できます。

1. スタイルと`[Verse]`、`[Chorus]`などのタグを付けた歌詞を入力します。
2. ABC欄の「ABCを生成」で中間楽譜だけを生成します。必要に応じて独立ABCエディタへ渡して編集します。
3. 楽曲の「生成」で現在のABCから音声を作ります。ABCが空なら同じ実行でABCも生成します。
   ABCプランを「なし」にするとABCを使わず直接生成します。
4. 生成済み音声を残したまま、楽曲欄の「生成」で作り直せます。

**ABCは1つのバリュー**（`yue2.abc`）：ABCエディタの文書は「ヘッダー」と「楽曲パートのリスト」からなり、パート一覧は見出し付きリストカードで表示します
ABC全体は1つのバリューとしてグリップでテキスト転送できます。ヘッダーは行テキストではなくYuE2記法のコントロールです。`M:` は拍子、`L:` は基準音価、`Q:` は四分音符のBPM、`K:` は調を指定します。`X:1`、空の `T:`、Vocal／Ins の声部定義はYuE2形式に合わせて固定です。拍子は全楽曲パートが空のときだけ変更でき、音符がある状態で `L:`／`K:` を変えるときは音の長さ・高さを保って再記譜します。正確に保てない場合は変更を拒否します。
テキストで入ってくるときは、最初の楽曲パートの「最初の素の `V: Vocal` 行」より上がヘッダーです。コメントなしで続く音符は名前なしの楽曲パートになります。
データ版8（`tools/migrate/008_yue2_abc_value.py`）が、旧形式（先頭パートがヘッダー）の保存データを変換します。

**プレビュー（ページ方式）**：楽譜は1行（4小節）ずつのページで表示します。再生が次のページへ進めばページもめくれます。
再生ボタンには今のページが「▶ 2/8」のように入ります（1ページだけなら「再生」）。再生ツールは「最初へ・前の譜表へ・再生・次の譜表へ・最後へ」で、最初へ／最後へは譜面の先頭／最後の譜表の頭へ移ります（再生中ならそこから鳴らし直します）。
レイヤの「コード」は、abcjsがコード記号から自動で作る伴奏のトラックです（譜表を持ちません）。外す（消音する）と楽譜のコード記号が薄くなり、鳴っているコード記号は再生中に色が付きます。
**プレビュー**：テキスト表示のときは曲情報・声部ボタン・再生ツールを隠し、切り替えだけを残します。狭い幅への対応はコアの mu-action-bar の定義（`is-thirds` / `mu-action-bar-start・middle・end・extra`）に任せ、このプラグインは幅ごとの CSS を持ちません。
**プレビュー**：複数小節の休符（`Z4`）は、表示のときだけ1小節ごとの休符（`Z|Z|Z|Z|`）に展開してabcjsに渡します（abcjsは `Z4` を、音は4小節・描画は1小節幅で扱い、2声部の音符が楽譜の上でずれて見えるため）。中身が空の読み取り専用プレビューはカードバーを出しません。

**プレビュー**：カード内の mu-action-bar にABCの状態、レイヤ（ポップアップのチェックリスト。外した声部は消音）、前後の譜表へ移動するボタン、中央の再生ボタン、テキスト／楽譜の切り替えをまとめます。消した声部は楽譜でも灰色になります。楽譜の声部名は「Vocal」「Ins」に縮めて描きます。曲の長さとテンポはレイヤの左隣の1行にまとめ、
楽譜は幅1100で組んで枠に合わせて拡縮します（1行4小節にそろえるため。幅が狭いとabcjsは入るだけ詰めて行ごとに3・5・8小節とばらつく。
読めなくなるので最小幅640px、それより狭いときは横にスクロール）。結果を持つアイテム（曲からABC）の
削除は主ボタンと排他（結果があれば主ボタンが「削除」）で、右上の小さい削除ボタンはカードそのものを消すためだけに使います。

**ピアノロール編集（譜面エディタ）**：ABCの楽曲パートは、譜面エディタでピアノロール（`yue2.roll`）として編集します。
音高×時間のグリッドに Vocal と Ins を色分けして並べ、コードを上の段に置きます。空いた所をクリックで音を追加
（ドラッグで長さ）、音をドラッグで移動、右端で長さ変更、Delete・矢印キーで削除・移動、コード段をクリックでコード追加。
読み書きは `abcmodel.js` が担当し、公式ツール
（`skills/yue2-music/scripts/abc_tools.py`）が定める方言に従います（音価は 1,2,3,4,6,8,12,16,24,32,48 の単位、
長いものはタイ、全休符は Z、コード変更は保持中の音をタイで分割、臨時記号は小節内で文字ごとに保持）。
方言の外の記法（リピート、`[K:]`、3連、歌詞行、楽曲パートをまたぐタイなど）は誤読せず、理由を出してテキスト編集に
とどめます。ロールで書き出した文章は、元の文書と同じ音（公式ツールで比較）になります。

テスト（公式ツールは YuE リポジトリの `skills/yue2-music/scripts/abc_tools.py`。検証用のABCは `tests/fixtures/yue2/`）：

```
node tests/yue2-header.mjs <出力先> <fixture.abc>...         # 単位・調・テンポを変えた版を書き出し、公式ツールで音の一致を確認
node tests/yue2-abcvalue.mjs <fixture.abc>...                  # ABC型バリュー（ヘッダー＋パート）の読み書き
node tests/yue2-abcmodel-refuse.mjs                       # 拒否すべき記法・既知の編集結果
node tests/yue2-abcmodel.mjs <fixture.abc>... --out <dir>  # 読み込み→書き出しの往復
python <abc_tools.py> compare <元> <往復後>                  # 公式ツールで音・コード・小節の一致を確認
node tests/yue2-abcfuzz.mjs <dir> 80                       # ランダムな編集を書き出す
python tests/yue2-abcfuzz.py <abc_tools.py> <dir>          # 公式ツールが読んだ結果とモデルの意図を照合
```

ABCエディタの試聴は簡易音源です。声部ごとの消音、楽譜の音符をクリックした位置からの
試聴ができます。歌声を含む完成音声は生成アプリで作ります。
楽曲はMP3／FLAC／Opusに対応し、成功時にMullionへコピーします。
コピーに失敗した場合はComfyUIの出力URLを使用します。

データ移行007は、生成側に保存されていたセクションリストを文字列へ戻し、
旧子ABCエディタを独立させます。ABCエディタが空なら生成側のABCを引き継ぎます。

検証は隔離したデータディレクトリでサーバーを起動し、Playwrightが利用できる環境で
`node tests/yue2-browser.cjs`を実行します。実モデルの生成は別途ComfyUIで確認してください。

ノード定義：[ComfyUI YuE2](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy_extras/nodes_yue2.py)。
abcjsとMITライセンスは`vendor/`に同梱しています。
